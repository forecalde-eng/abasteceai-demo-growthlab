# Preparación y lotes DEMO

DOCUMENTO FICTICIO DE DEMOSTRACION
Contar unidades de inventario del catálogo. Preparar cantidades aprobadas. Separar lotes; no reservar lotes vencidos. Registrar diferencias antes de despachar. Los pesos y volúmenes usados son supuestos de demostración. Este texto no contiene instrucciones de manejo químico.
